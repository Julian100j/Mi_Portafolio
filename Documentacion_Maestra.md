Actúa como un Ingeniero de Software Senior, Arquitecto Frontend, Diseñador UI/UX y especialista en desarrollo web moderno.

Necesito que diseñes y desarrolles un portafolio web profesional, moderno, completo y responsive para una estudiante/ingeniera de Sistemas. Este portafolio debe servir para presentarse profesionalmente ante empresas, reclutadores, docentes, clientes y posibles empleadores.

El objetivo principal es crear una página web visualmente atractiva, rápida, profesional, organizada y fácil de mantener, donde se pueda mostrar información personal, perfil profesional, proyectos, tecnologías, GitHub, certificados, formación académica, experiencia, habilidades y medios de contacto.

Quiero que el resultado final se vea como un portafolio real de nivel profesional y no como una plantilla básica de estudiante.

### 1. Tecnologías del proyecto

Desarrolla el proyecto utilizando:

* React.
* Vite.
* JavaScript moderno.
* Tailwind CSS.
* React Icons o Lucide Icons.
* Framer Motion para animaciones suaves si consideras que aporta valor.
* Git y GitHub.
* Diseño completamente responsive.
* Buenas prácticas de desarrollo frontend.

Evita dependencias innecesarias y mantén una arquitectura limpia y escalable.
